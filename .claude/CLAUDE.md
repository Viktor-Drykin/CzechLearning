# Фрагмент для CLAUDE.md

Вставить в `CLAUDE.md` в корне репозитория. Claude Code подтягивает этот файл на каждой задаче,
поэтому правила ниже действуют без напоминаний в промпте.

---

## Дизайн

Единственный источник правды по внешнему виду — `DesignSystem.md` в корне репозитория.
Перед любой задачей, которая трогает UI, прочитай его.

**Цвета.** Только токены из `DesignSystem/Colors.swift` (`AppColor.…`). Литералов цвета
во вьюхах быть не должно — ни `Color(red:green:blue:)`, ни hex, ни `.blue`/`.red`.
Если нужного токена нет — добавь его в `Colors.swift` и в таблицу `DesignSystem.md`,
а не подбирай цвет на месте.

**Шрифты.** Только `.appFont(AppFont.…)` из `DesignSystem/Typography.swift`.
Прямой `.font(.system(size:))` и `.font(.title)` во вьюхах не использовать.
Ограничение Dynamic Type стоит один раз на корневой вьюхе — не дублировать его по экранам.

**Размеры.** Отступы, радиусы и высоты — из `DesignSystem/Metrics.swift`
(`AppSpacing`, `AppRadius`, `AppSize`). Числовых литералов размеров во вьюхах быть не должно,
кроме толщины линий 1 pt и `lineLimit`.

**Тёмная тема.** Отдельных вьюх и веток `if colorScheme == .dark` не бывает: все токены
динамические. Если экран в тёмной теме выглядит неправильно — чинить токен, а не вьюху.

**Что не рисуем.** Статус-бар и клавиатуру система кладёт поверх макета — свои не рисовать.
Эмодзи как иконки интерфейса не использовать, только SF Symbols.

**Доступность.** Интерактивные элементы — настоящие `Button`, `NavigationLink`, `TextField`
с `Label`; область касания не меньше `AppSize.minTouchTarget`. Кнопкам без подписи —
`accessibilityLabel`. Чешский текст оборачивать в `Text.czech(_:)`, чтобы VoiceOver читал
его чешским голосом.

**Порядок оценок.** На всех экранах слева направо: `Снова → Трудно → Хорошо → Легко`.
Цвета берутся из `AppColor.grade(_:)`. Строки интервалов приходят готовыми из `SRSScheduler`;
вьюха их не вычисляет.

**Макеты.** Дизайн экранов лежит на холсте, разбитом по этапам реализации из ТЗ (раздел 14).
Если к задаче приложен скриншот экрана — он для сверки результата, а не исходник:
верстать по `DesignSystem.md` и ТЗ, скриншотом проверять.
